# DS Cause Discovery

A Claude Code skill project for cause discovery and analysis.

## Setup

```bash
git clone git@github.com:Leucanthos/DS-cause-discovery.git
cd DS-cause-discovery
```

Then use Claude Code in this directory — the skills in `.claude/skills/` will be
automatically available.

## Skills

| Skill | Description |
|-------|-------------|
| `cause-discovery` | Root cause analysis via 5 Whys, causal chains, and structured inquiry |

## Structure

```
.claude/
  skills/         # Skill definitions (Anthropic format)
  settings.json   # Project config
CLAUDE.md         # Project instructions for Claude
```
