# Cause Discovery

A skill for discovering and analyzing root causes through structured inquiry.

## When to Use

Invoke this skill when the user wants to:
- Trace a symptom or effect back to its underlying causes
- Analyze why something happened or is happening
- Use structured frameworks like 5 Whys, Fishbone diagrams, or causal chains
- Discover non-obvious contributing factors

## Framework

### 1. Problem Definition
Clarify the effect or symptom being analyzed:
- What exactly is observed?
- When and where does it occur?
- What is the scope and impact?

### 2. Cause Elicitation
Use layered questioning to surface causes:
- **5 Whys** — Iteratively ask "why" to drill from symptom to root cause
- **Causal Chain Mapping** — Link causes to effects in dependency order
- **Contributing Factors** — Identify necessary vs. sufficient conditions

### 3. Validation
Test each candidate cause:
- Would removing this cause prevent the effect?
- Is there evidence linking cause to effect?
- Are there counterexamples or alternative explanations?

### 4. Synthesis
Organize findings into a coherent explanation:
- Primary root cause(s)
- Contributing factors
- Recommendations for intervention

## Output Format

Present findings as:
1. **Summary** — One-paragraph causal explanation
2. **Causal Chain** — Bulleted list from root cause → intermediate causes → effect
3. **Confidence** — High / Medium / Low with rationale
4. **Recommendations** — Actionable next steps
